# Rev K 取付と検証

2026-11-27の指定「左右とも電源・RESETはF面、マイコンはB面」を反映した。

|部品|左基板|右基板|
|---|---|---|
|XIAO nRF52840 Plus|B面、部品面をキャリアへ向ける|B面、部品面をキャリアへ向ける|
|RESETボタン|F面|F面|
|スライド電源スイッチ|F面|F面|

基板名の末尾にF/B、マイコン付近にXIAO B、電源にPWR F、RESETにRST Fを両面印字した。表裏画像も参照する。

## 変更内容

- 左XIAOの主端子14本を反転し、B面取付けに合わせて再配線。
- 左電源・RESETのパッドを、同じ部品をF面に実装する向きへ反転して再配線。
- 電源スイッチの位置決め穴は左右2個ずつ、公称φ0.90 mm。元Gerberの0.0354 inchを基に、現スイッチの反転・+0.8 mm移動に合わせた位置に配置。
- B+・B−、C1〜C6、R1〜R5、RST、PWR、追加GPIO、予備GPIO、センサー端子名の印字を継承。
- 右下のセンサー端子は、F面からUSBを上に見て左からGND / MOTION / SCLK / SDIO / CS / VCC。
- 固定穴4個の中心とφ4 mm、外形、右下10 mm延長、キャリア厚1.6 mmを維持。

## 検証

- KiCad DRC違反0、未配線0。
- XIAO左右のB面取付けを前提に、主端子の番号別座標をSeeed公式Plus基板と照合。両基板ともF面から見て左列D0〜D6、右列VBUS/GND/3V3/D10/D9/D8/D7。
- パッド配置・実装面・銅箔・マスク・ペーストを検査。
- 出力GerberのF.CuにRESET各4パッド、電源各7パッドが左右ともあること、B.Cuにスイッチパッドがないことを確認。
- 位置決め穴4個の座標・φ0.90 mmが出力NPTHに含まれることを確認。NPTHは分割用12点を含め計16点。
- 全PTH154点（ビアを含む）とNPTH16点を、基板データと座標・径で照合。
- キーマトリクス、電源、RESET、左エンコーダー、右PMW3610、予備GPIOの接続を検査。
- GPIOの信号割当は既存XIAO用ファームウェアと同じ。左主端子の物理位置が変わったため、Rev Kの接続表を使用する。
- ZIPを再読込し、各ファイルが検証済み出力と一致することを確認。

## 発注・組立

使用ファイルは **Y13-XIAO-revK-order-gerbers.zip**。FR-4・2層・板厚1.6 mm。

高さと支持部材は実物で調整する。XIAOの追加線13本（左7本・右6本）を接続し、電池を外した状態で極性・短絡・導通を確認してからUSBで試験する。

マイコンは左右ともB面へ載せる。Rev J以前の取付配置・接続座標とは混同しない。ユーザーの新指定により取付面が確定したため、Rev Jで保留としていた実装面照合の条件をこの構成へ更新した。

ケース内の機構適合、電池の保護仕様・充電電流・充電完了、実機のキー・無線・センサー動作は未検証。1100 mAh電池と充電タイマーの懸念も残る。
