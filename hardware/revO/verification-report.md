# XIAO nRF52840 Plus - Semigorou / Rev O

D0〜D19の接続点を左右それぞれ用意するため、追加端子D11〜D19に対応するφ0.65 mmのPTH穴を左右9個ずつ配置した。座標はSeeed公開PCBの端子配置と照合。従来の離れた追加配線用穴は置換した。

通常14端子の穴位置・穴径1.0 mmは維持し、銅箔パッド径を1.7 mmから1.4 mmへ変更。配線幅0.15 mm（左予備D13の一部は0.13 mm）、信号間隔0.15 mmを基本として再配線。PCB厚1.6 mm、固定ネジ穴・USB基準位置・外形、電源とRESETのF面実装、XIAOのB面実装は維持。

使用中のD11/D12はマトリクスへ、右D13/D19はセンサー端子へ接続。左D13/D17/D18は既存予備端子へ接続し、ほかの未使用追加端子は対応穴で取り出す。D14/D15はNFC兼用で利用時にファームウェア設定が必要。D16/P0.31はXIAOの電池測定回路に接続されており、汎用の空きGPIO扱いはしない。キャリア側でD16を電池＋へ直結していない。

追加穴を設けても、XIAOと穴の間の接触は自動的に成立しない。ピン・はんだ付け・支持部材・絶縁は別途検討する。BAT+とRESETの接続も従来同様に別途必要。GPIO用途・ファームウェアの既存割当は変更していない。

URLと製品名の2行はBシルクのまま。実装高さ・ケース適合・充電・無線の実機検証は未実施。

最終検証：DRC違反0、未接続0。PTH183、NPTH16を基板と照合し、追加φ0.65 mm穴18個の座標も個別照合済み。
