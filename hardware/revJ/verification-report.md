# Rev J 修正と再検証

2026-11-27。電源スイッチの位置決め穴と印字を修正した。左スイッチの実装面は、ユーザーが左マイコンを旧基板名の印字側（F面）に載せているという回答に合わせ、B面を指定している。旧ZIPもB面だったため、実物で同じ面になったという報告との照合は残っている。

## 確認した不具合と修正

|項目|Rev Iで確認した内容|Rev Jの修正|
|---|---|---|
|左RESET SW1・電源SW3|ZIP内の銅箔・マスクを確認するとB面。旧基板名はF面。実物での面違いという報告と食い違う|マイコンを旧基板名印字側（F面）に載せる回答に合わせ、反対のB面を指定。F/BおよびPWR B・RST Bを印字し、表裏画像を追加。実物写真・発注ファイルとの照合待ち|
|電源SW3・SW4の穴|元GerberのNPTHにある位置決め穴4個が欠落|各スイッチにφ0.90 mmの非メッキ穴を2個ずつ追加|
|電池端子の表示|B+・B−の印字がなかった|左右の電池入力端子とXIAO BAT線の受けパッドにB+・B−を両面印字|
|配線時の識別|行列端子等の表示が不足|C1〜C6、R1〜R5、D6/D8、予備GPIO、追加GPIO、RST、PWR、センサー6信号を両面印字|

以前の検査では、元の位置決め穴を照合する項目が抜けていた。実装面についてはフットプリントのレイヤーの比較だけで判断し、ユーザーの実装方向との照合が不十分だった。今回は出力Gerberの実際のSW1〜SW4のパッドと、NPTHの座標・径を検査した。

## 実装面

Rev Jでは**左SW1・SW3はB面、右SW2・SW4はF面に実装**する。front.pngはF面から、back.pngはB面から見た向きで表示している。左右の名前は各基板のLEFT/RIGHT印字で区別する。今回から基板名にF/Bを両面で明記した。

当初の「左をFへ変更」という案は、左マイコンが旧基板名の印字と同じ側に載るという回答を受けて取り消した。Fへ移すと、その条件ではマイコンと同じ面になるため。旧Rev Iの実物両面と、実際に発注したZIPが未照合のため、面違いの原因は未特定。

基板のF/Bの判断はプレビューのパッド・穴・配線形状と照合する。XIAOを部品面がキャリアに向くように取り付ける条件と、高さ・スペーサーを実物で調整する方針は引き続き適用する。

## 復元した位置決め穴

元ファイルadapter-NPTH.drlのT1は0.0354 inch（0.89916 mm）。Rev Jでは公称φ0.90 mmを採用した。元の4座標を、左のB面実装、右のF面への反転、奥方向+0.8 mmの移動に合わせて変換している。

|スイッチ|穴中心X mm|穴中心Y mm|径 mm|
|---|---:|---:|---:|
|左 SW3|132.05968|75.47092|0.90|
|左 SW3|135.05942|75.47092|0.90|
|右 SW4|179.11894|75.45060|0.90|
|右 SW4|176.11920|75.45060|0.90|

元データの1.5 mm穴4個は、現在の設計に搭載しないTRRSコネクター位置のもの。今回の電源スイッチ穴とは別に扱う。

## 電池・RESET・センサー配線

- 左電池入力はJ3、右はJ6。各1番がB+、2番がB−。電池入力B+はSWの3番、SWの2番からXIAO BAT+へ接続する。
- 電源SWをOFFにすると電池入力B+とXIAO BAT+は切り離される。両方の受けパッドにB+と表示しているが、OFFでの導通はない。
- RST受けパッドはXIAO TP2へ追加線で接続する。RESETボタンはRSTをGNDへ接続する。
- 右下J8は、F面からUSBを上に見て左→右に**GND / MOTION / SCLK / SDIO / CS / VCC**。
- センサーVCCはXIAO 3V3からR_SENSOR（0Ω）を経由する。MOTION＝D6、SCLK＝D8、SDIO＝D19、CS＝D13。
- 左の予備GPIOはD13・D17・D18。キー用GPIO、左エンコーダー、右センサー、電池電圧測定、充電電流選択との重複がないことを確認した。

## 検査結果

- KiCad 9.0.7のDRC違反0、未配線0。
- 新しい穴と左スイッチ周囲の配線を引き直した。その他の端子の位置・信号名、外形をRev Iと照合。
- 元Gerberにある電源スイッチの7個のSMDパッドの座標を、反転・移動を含めて照合。
- 元NPTHから4穴を独立に読取り、Rev Jのパッドと出力ドリルの座標・径を照合。
- 出力B.Cuに左SW1の4パッド・SW3の7パッド、F.Cuに右SW2の4パッド・SW4の7パッドがあることを確認。
- PTHの全穴（ビアを含む）およびNPTH16点（分割用12＋スイッチ用4）を基板データと全数照合。最終穴数はGerber検証JSONに記録。
- XIAO主端子14本×左右をSeeed公式Plus基板の座標と照合。固定穴4個の中心・φ4 mm、板厚1.6 mmを確認。
- キーマトリクス、電源SW、RESET、左エンコーダー、右PMW3610、予備GPIOを独立の接続表で検査。
- 既存XIAO用ファームウェアのGPIOと基板の信号対応を再照合。GPIO変更はない。
- ねじ頭径8 mmを仮定した他銅箔との保守的最小余裕は約0.238 mm。
- ZIPを読み直し、含まれる各ファイルが検証した出力と一致することを確認。

## 発注・組立

修正版Gerberは **Y13-XIAO-revJ-order-gerbers.zip**。FR-4・2層・板厚1.6 mm。Rev I以前のZIPは旧版。再発注前に、報告された左実装面の違いを実物写真・発注ZIPと照合する必要がある。

実物の組立、ケース適合、電池の仕様と充電電流、充電終了、無線通信は実機で確認する。1100 mAh電池の充電タイマーに関する懸念は今回の基板修正では解決していない。通電前には、B+とB−の極性、追加線13本の導通、隣接パッドの短絡、RESETの押下時の導通を確認する。

スイッチの機械的な適合は、元Gerberの形状・穴位置への照合結果。手元の部品を修正版へ実装した試験は未実施。
